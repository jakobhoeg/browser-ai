---
title: "Overview"
description: wllama (llama.cpp) model provider for Vercel AI SDK v7
---

The `@browser-ai/wllama` package enables you to run any [GGUF](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md) model directly in the browser with [wllama](https://github.com/ngxson/wllama), a WebAssembly port of [llama.cpp](https://github.com/ggml-org/llama.cpp), with seamless integration with the Vercel AI SDK v7. If a model exists as a GGUF file, you can run it - no pre-compiled model list, no conversion step.

### What's Included

- **Any GGUF Model**: Load models from Hugging Face or a direct URL
- **WebGPU Acceleration**: GPU inference when available, with CPU fallback
- **Tool Calling**: Native llama.cpp function calling support
- **Structured Output**: JSON schema enforcement via grammar-constrained sampling
