Add `@browser-ai/litert-lm`, a Vercel AI SDK v7 provider for Google LiteRT-LM (LiteRT.js). It runs Gemma and other LLMs entirely in the browser via WebGPU, with the same `streamText`/`generateText` ergonomics as the other `@browser-ai` providers. (Text-in / text-out; tool calling and JSON mode are not yet exposed by the LiteRT-LM Web SDK.)
